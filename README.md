🧬 Scientific Purpose

BioAlignAI is being developed as a computational biology project focused on making sequence-analysis workflows more accessible through an interactive interface.

The project is intended for educational, research, and bioinformatics development purposes.

Results should be independently validated before being used for clinical or diagnostic decisions.
